Основні поняття — Випадкові величини

Випадкова величина — це функція, яка відображає кожен елемент простору елементарних подій у дійсне число.

X : Ω → ℝ

Число x, якого набуває X при проведенні випадкового випробування, називається реалізацією або значенням X.


Приклад:

Ω = «Монету підкидають чотири рази». X = «Кількість гербів».

Для змінної X можливі значення 0, 1, 2, 3 і 4, проте перед кожним новим кидком невідомо напевно, яке саме з цих значень реалізується.

Основні поняття — Розподіл ймовірностей

Випадкова величина X називається дискретною, якщо вона може набувати лише скінченної або зліченно нескінченної кількості значень x1, x2, ..., xk, ...

Розподіл ймовірностей величини X задається ймовірностями:

P(X = xi) = pi,     i = 1, 2, ..., k, ...

Функція ймовірностей f(x) дискретної випадкової величини X визначена для x ∈ ℝ як:

f(x) = { P(X = xi) = pi, при xi ∈ {x1, x2, ..., xk, ...};   0, в іншому випадку }

Основні поняття — Функція розподілу

Функція розподілу дискретної випадкової величини X — це функція F(x), яка кожному значенню xi ставить у відповідність кумулятивну ймовірність:

F(xi) = P(X ≤ xi) = f(x1) + ... + f(xi)

Приклад: Монету кидають двічі. X = {«Кількість гербів»}.

X012
f(x)0,250,50,25
F(x)0,250,751
F(x) = 0, якщо x < 0
F(x) = 0,25, якщо 0 ≤ x < 1
F(x) = 0,75, якщо 1 ≤ x < 2
F(x) = 1, якщо 2 ≤ x

Основні поняття — Експеримент Бернуллі

Часто у випадковому процесі нас цікавить лише одне питання: настала подія A чи ні? Це найпростіший випадок у статистиці — випробування Бернуллі.


Принцип: ми переводимо результат у числа за допомогою величини-індикатора:

  • X = 1, якщо подія A настала («Успіх»)
  • X = 0, якщо подія A не настала («Невдача»)

Розподіл Бернуллі: якщо позначити ймовірність успіху через π:

P(X = 1) = π
P(X = 0) = 1 − π
