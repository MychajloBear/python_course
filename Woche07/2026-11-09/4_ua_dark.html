Основні поняття — Випадкові величини

Випадкова величина — це функція, яка відображає кожен елемент простору елементарних подій у дійсне число.

X : Ω → ℝ

Число x, якого набуває X при проведенні випадкового випробування, називається реалізацією або значенням X.


Приклад:

Ω = «Монету підкидають чотири рази». X = «Кількість гербів».

Для змінної X можливі значення: 0, 1, 2, 3 і 4. Проте перед кожним новим кидком невідомо напевно, яке саме з цих значень випаде.

Основні поняття — Розподіл ймовірностей

Випадкова величина X називається дискретною, якщо вона може набувати лише скінченної або зліченно нескінченної кількості значень x1, x2, ..., xk, ...

Розподіл ймовірностей величини X задається ймовірностями:

P(X = xi) = pi,    i = 1, 2, ..., k, ...

Функція ймовірностей f(x) дискретної випадкової величини X визначена для x ∈ ℝ як:

f(x) = { P(X = xi) = pi, при xi ∈ {x1, x2, ..., xk, ...};   0, в іншому випадку }

Основні поняття — Функція розподілу

Функція розподілу дискретної випадкової величини X — це функція F(x), яка кожному значенню xi ставить у відповідність сумарну (кумулятивну) ймовірність:

F(xi) = P(X ≤ xi) = f(x1) + ... + f(xi)

Приклад: Монету кидають двічі. X = {«Кількість гербів»}.

X012
f(x)0,250,500,25
F(x)0,250,751,00
F(x) = 0, якщо x < 0
F(x) = 0,25, якщо 0 ≤ x < 1
F(x) = 0,75, якщо 1 ≤ x < 2
F(x) = 1, якщо 2 ≤ x

Основні поняття — Експеримент Бернуллі

Часто нас цікавить лише одне питання: настала подія A чи ні? Це найпростіший випадок у статистиці, відомий як випробування (експеримент) Бернуллі.


Принцип: ми трансформуємо результат у числа за допомогою індикаторної величини X:

  • X = 1, якщо подія A настала («Успіх»)
  • X = 0, якщо подія A не настала («Невдача»)

Приклади:

• Кидок кубика: чи випало парне число? (Так = 1, Ні = 0)

• Медицина: чи допомогли ліки пацієнту? (Одужання = 1, Ні = 0)

P(X = 1) = π
P(X = 0) = 1 − π

Дискретний рівномірний розподіл

Дискретна випадкова величина X називається рівномірно розподіленою, якщо всі її значення рівноймовірні:

P(X = xi) = 1⁄k

Випадкова величина X = «Кількість очок» при киданні грального кубика є класичним прикладом: кожне з 6 значень має однакову ймовірність 1/6.

Геометричний розподіл

Випробування Бернуллі з ймовірністю π = P(A) повторюється доти, доки подія A не настане вперше.

X = «Кількість спроб до першої появи події A».

Геометричний розподіл — це по своїй суті розподіл «Скільки ще потрібно чекати?».


Дискретна випадкова величина X називається геометрично розподіленою з параметром π. Позначення: X ~ G(π).

Геометричний розподіл — Приклад

Штрафні кидки в баскетболі. Відсоток влучань становить 20%, отже p = 0,2. Ви кидаєте до першого влучання, після чого зупиняєтесь.


  • p = 0,20: ймовірність влучання (успіх).
  • 1 − p = 0,80: ймовірність промаху (невдача).
  • k = 4: шукаємо ймовірність, що саме 4-й кидок стане першим влучним.
P(X = k) = (1 − p)k−1 ⋅ p
P(X = 4) = 0,803 ⋅ 0,20 = 0,512 ⋅ 0,20 = 0,1024 (близько 10,2%)

Статистичні показники — Математичне сподівання

Математичне сподівання E(X) дискретної випадкової величини:

E(X) = x1⋅p1 + ... + xk⋅pk = ∑ xi⋅pi

Позначення: μX, μ.


Приклад для грального кубика:

E(X) = 1⋅(1/6) + 2⋅(1/6) + 3⋅(1/6) + 4⋅(1/6) + 5⋅(1/6) + 6⋅(1/6) = 3,5.

3,5 — це теоретичне середнє значення при нескінченно великій кількості кидків, хоча число 3,5 на жодній грані кубика не випадає.

Математичне сподівання vs. Середнє арифметичне

Математичне сподівання є зваженим середнім теоретичних значень із вагами-ймовірностями pk.


  • Середнє арифметичне описує центр реальних емпіричних даних, які ви вже зібрали.
  • Математичне сподівання описує центр теоретичного розподілу.

Його можна визначити аналітично без збору даних і проведення експерименту — центр моделі відомий завчасно.

Дисперсія та стандартне відхилення

Дисперсія дискретної випадкової величини:

Var(X) = E((X − μ)2)

Вона показує, наскільки далеко значення в середньому відхиляються від математичного сподівання («середній квадрат відхилення»).


Стандартне відхилення:

σ = √Var(X)

Правило спрощення обчислень (формула зміщення):

Біноміальний розподіл

Розглядається серія з n незалежних повторень експерименту Бернуллі зі сталою ймовірністю успіху π = P(A).

X = «Кількість випробувань, у яких подія A настане».


Приклад: кидаємо кубик 10 разів і рахуємо кількість випадань «шістки».

Біноміальний розподіл — Python

Виробництво: 95% деталей якісні, 5% дефектні (p = 0,05). Купуємо n = 10 деталей.

from scipy.stats import binom n = 10 p = 0.05 k = 2 # Ймовірність знайти рівно k бракованих деталей (PMF) prob_exact = binom.pmf(k, n, p) print(f"Ймовірність для точно {k} бракованих деталей: {prob_exact:.4f}") # Кумулятивна ймовірність: "Щонайбільше k деталей" - P(X <= 2) = P(0) + P(1) + P(2) prob_upto = binom.cdf(k, n, p) # Cumulative distribution function print(f"Ймовірність для щонайбільше {k} бракованих деталей: {prob_upto:.4f}")

Розподіл Пуассона

Геометричний розподіл рахує кількість спроб до першого успіху (множина значень ℕ не обмежена зверху, на відміну від біноміального, що обмежений n).


Розподіл Пуассона також моделює процеси підрахунку. Він рахує кількість подій, які відбуваються протягом фіксованого інтервалу часу або заданої області простору. Кількість подій не обмежена зверху.


Приклади:

• Кількість страхових випадків за один рік.

• Кількість хворих на грип протягом місяця.

Розподіл Пуассона — Параметри

Випадкова величина називається пуассонівською з параметром λ > 0: X ~ Po(λ).

При більших λ (λ ≥ 10) розподіл стає практично симетричним.

E(X) = λ
Var(X) = λ

Лямбда (λ) — це середня частота (інтенсивність) настання події за період.

Якщо на підприємстві ламається в середньому 2 верстати на місяць, то λ = 2.

На відміну від біноміального розподілу, тут не потрібні ні фіксоване n, ні p. Потрібно знати лише середній показник появи події.

Розподіл Пуассона — Python

На автобусну зупинку кожні 10 хвилин приходить у середньому 3 особи (λ = 3). Ймовірність появи 5 або щонайбільше 5 осіб:

from scipy.stats import poisson lam = 3 # Параметр Lambda (середнє значення за інтервал) k = 5 # Шукана кількість подій prob_exact = poisson.pmf(k, lam) # Кумулятивна ймовірність (CDF): "Щонайбільше 5 осіб" P(X <= 5) prob_upto = poisson.cdf(k, lam) print(f"Ймовірність щонайбільше {k} осіб: {prob_upto:.4f}")

Розподіл Пуассона — Інтуїція моделі

Розподіл Пуассона застосовується завжди, коли події з'являються незалежно одна від одної у фіксованій області (у часі або просторі).


Наочний приклад: сніжинки на тротуарній плитці.

Коли сніг іде рівномірно, на кожну плитку потрапляє в середньому, наприклад, 50 сніжинок. Але на одну плитку впаде 42, на іншу — 58. Це чиста випадковість, яка підпорядковується саме закону Пуассона.
